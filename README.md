# SoftUni Bazar

An ASP.NET Core MVC marketplace application where users can create, browse, and manage ad listings. Built as a SoftUni exam project.

## Features

- User authentication (register, login, logout) with ASP.NET Core Identity
- Create, edit, and delete ad listings
- Browse ads by category
- Add ads to your cart as a buyer

## Tech Stack

- **Framework:** ASP.NET Core MVC
- **Database:** Entity Framework Core with SQL Server
- **Authentication:** ASP.NET Core Identity
